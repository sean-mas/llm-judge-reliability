4c. ROGAN-GLADEN CORRECTION
    Judges are poor gates. Are they usable as meters, if calibrated?

    *** READ THIS BEFORE USING THE NUMBERS BELOW. ***
    Calibrating TPR and TNR on the same sample whose flag rate is then
    corrected is CIRCULAR. Substituting flag = TPR*p + (1-TNR)*(1-p)
    into the estimator returns p exactly, as algebra, for any judge
    however bad. The point estimates below are therefore an identity
    check on the implementation, NOT evidence that the method works.
    Only the interval width is informative here: it says how precisely
    a calibration set of this size pins the rate down.

    The non-circular version is calibrate-on-dev, apply-to-test, and it
    runs from `--split test`. That is the number the paper reports.

    judge                   flag    TPR    TNR      J  corrected            95% CI
    tier1_paid             19.2%  0.260  0.949  0.210      67.3%   [ 61.7%,  72.8%]
    tier2_hosted_open      29.0%  0.372  0.874  0.246      66.9%   [ 61.1%,  72.6%]
    tier3_local            24.1%  0.327  0.926  0.253      66.1%   [ 60.5%,  71.7%]

    true rate for comparison: 67.2%
    J = Youden's J = TPR + TNR - 1, the estimator's denominator.
    A small J means the correction is arithmetically unstable, so read
    the interval rather than the point estimate.
